# Planning Grid site

**See your work. Shape your week.**

Planning Grid is an independent browser extension in development
for viewing Todoist tasks in a grid and planning your week.

This repository contains static files served by GitHub Pages.
Its initial purpose is to host the extension's public OAuth
client metadata document.
The document is served from `oauth/client.json`.

The extension's source code lives in a separate private repository.

Planning Grid is not created by, affiliated with, or supported by Todoist.
